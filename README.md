![Logo](logo.png)

**SVJedi-Tag** is a structural variant genotyping tool designed to genotype inversions from linked-read sequencing data. It leverages the barcode signals specific to linked-read technology and combines them with a genotype likelihood model to estimate the genotype of a sample for a set of target inversions.

SVJedi-Tag first constructs a variation graph from the reference genome and a set of structural variants, including the target inversions as well as nearby structural variants that may affect genotyping accuracy (e.g., variants located close to inversion breakpoints). Linked reads are then aligned to the variation graph using VG Giraffe (v1.54.0). Finally, barcode signals extracted from these graph alignments are analyzed and integrated into the genotype likelihood framework to infer the most likely genotype for each inversion.

# Installating SVJedi-Tag

You can install and use the SVJedi-Tag Conda package directly.
```
conda install SVJedi-Tag
```

Alternatively, you can install the dependencies manually and clone the repository from GitHub.

**Packages dependencies**
- VG toolkits (version = 1.54.0)
- GFAGraphs (version 0.3.4) (Warning : GFAGraphs require python version 3.10 or higher and the packages networkx, tharos-pytools, matplotlib, mycolorpy)

```
#VG installation command in a conda environment 
conda install bioconda::vg

#GFAGraphs installation command
pip install gfagraphs

#If necessary
pip install networkx
pip install matplotlib
pip install biopython
pip install tharos-pytools
```

git clone git@github.com:MTemperville/SVJedi-Tag.git

# Using SVJedi-Tag

### Intput files


* Linked-reads file (.fastq /.fq /.fastq.gz /.fa.gz)
* Variant calling file (.vcf)
* Reference genome file (.fasta/.fa)

### File specificities : 
#### Linked-read file requirement (FASTQ)

The sequence of each read should not contain the barcode sequence. The barcode information must be present in the header of each read in the following format (no space before the barcode): 
>headerBX:Z:XXXX

Please note that the full headers must not contain any tabulation. 

The `format_fastq.py` script can be used to format the file so that the headers correspond to the expected format.
```
python format_fastq.py -q <initial linked-read file> -o <formated linked-reads file>
```

#### Variant calling file (VCF)
The file must contain the inversions to be genotyped. It may also contain other types of structural variants that could have an impact on the genotyping of the inversions because of their position close to the breakpoints of the inversions.
* The file must be a tabulated file with a standart vcf format : 
>#CHROM	POS	ID	REF	ALT	QUAL	FILTER	INFO

*Example:* 
```
##fileformat=VCFv4.3
##fileDate=2025-03-05
##ALT=<ID=INV,Description="Inversion">
##INFO=<ID=END,Number=1,Type=Integer,Description="End position on reference genome">
##INFO=<ID=SVTYPE,Number=1,Type=String,Description="Type of the SV">
##INFO=<ID=SVSIZE,Number=1,Type=Integer,Description="Size in nt of the SV">
#CHROM	POS	ID	REF	ALT	QUAL	FILTER	INFO
Chr1	1173997	INV1	N	<INV>	.	.	END=2173996;SVTYPE=INV;SVSIZE=1000000
Chr1	2287235	INV2	N	<INV>	.	.	END=3287234;SVTYPE=INV;SVSIZE=1000000
Chr1	4393271	INV3	N	<INV>	.	.	END=5393270;SVTYPE=INV;SVSIZE=1000000
```

## Command line and parameters

```
python svjedi-tag.py -v <vcf_file.vcf> -r <reference_genome.fa> -q <linked-reads_file.fastq> -p <output_path/prefix>
```

**Warning:** The linked-read file must be pre-processed to link BX tag to the header (`HeaderBX:***`) and no tabs in the header (See **File specificities**).

If you alredy have the variation graph (GFA) generated by SVJedi-Tag and the alignment file (GAF) genetared by VG Giraffe, you can directely run de genotype prédiction step:
```
predict_genotype.py -a <alignment_GAF_File> -g <Graphe_GFA_File> -v <input_VCF> -o <outputVCF>
```

### Parameters

```
    -v     VCF file containing the target inversions to genotype. 
    -r     Reference genome file. 
    -q     Interleaved linked-read FASTQ file or two paired-end FASTQ files 
    -p     Output path and/or prefix
    -s     Signal barcode region size (Default: 10kp).
    -i     Breakpoint inaccuracy tolerance (bp) (Default: 0).
    -d     Minimum difference between the two bigger genotype likelihood (Default: 20).
    -a     GAF alignment file of linked reads against the graph (output of vg giraffe).
    -g     GFA graph file generated by SVJedi-Tag.
    -t     Number of threads (Default 1)
```

## Output files

#### Output VCF 
SVJedi-Tag's output is a vcf file containing all the input inversions associated to their genotype. It contains a *SAMPLE* column containing the predicted genotypes and genotyping information.

- GT : Genotype, assuming a diploid individual: either `0/0`, `0/1`, or `1/1`. A `./.` value indicates a missing value due to an insufficient number of informative barcodes in the breakpoint regions.
- DP : Total number of distinct barcodes in the breakpoints regions
- AD : Number of barcodes supporting the absence of the inversion, Number of barcodes supporting the presence of the inversion, Number of non-informative barcodes.
- AF : Alternative allele ratio

```
Example : 
GT:DP:AD:AF	1/1:159:0,99,60:1.0 
```
#### GFA file
The GFA file contains the graph (in GFA format) constructed from the reference genome and the intput VCF file. It can be used to restart SVJedi-Tag by skipping the graph creation step.
#### GAF file 
The GFA file is the VG Giraffe output file (in GAF format), it contains the read alignments to the graph. It can be used to restart SVJedi-Tag by skipping the alignment step.
